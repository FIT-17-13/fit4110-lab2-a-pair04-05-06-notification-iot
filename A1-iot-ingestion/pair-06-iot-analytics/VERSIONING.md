# Versioning Rules

- Version format: MAJOR.MINOR.PATCH (SemVer).
- Start at v1.0.0 for the first agreed contract.
- Increment PATCH for backward-compatible fixes (typo, description).
- Increment MINOR for backward-compatible additions (new optional fields, new events).
- Increment MAJOR for breaking changes (rename fields, remove events, change required fields).
- Changes must be recorded in negotiation log before version bump.
